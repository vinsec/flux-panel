# P1 隔离验收报告

2026-10-26。P1 功能 **11–19、29 已实现**，第 20 项完成本轮虚拟内网与原生 VPS 的规模、持续负载、多核、崩溃和升级回滚验收。**独占物理机 PMU/perf 归因、真实主机掉电和更长周期 soak 未执行**，不将这些项目标成通过。生产灰度第 10 项及 P2 第 21–27 项继续保留。

## 同条件性能回归

独立 ARM 虚拟机；每组 3 次，交错顺序；MTU 1500。最终包 81 组传输、45 组延迟采样全部完成。TCP 每次 **1 GiB 接收端字节回执**，另有 150 Mbps × 8 秒固定速率 CPU 对照、50 Mbps/1200 B 和 5 Mbps/64 B UDP。高级路径在此使用数字 IPv4 单目标，未打开人为带宽上限；各可选功能的正确性由上面的功能矩阵覆盖。

10k 下，兼容路径吞吐相对 C7 为 **-1.9%**，固定速率 CPU 成本 **-3.1%**；高级路径分别约 **-3.5%**、**+3.5%**。未观察到随 N 发生逐包线性退化；新增功能有管理开销，不能承诺所有吞吐、CPU、延迟指标同时提高。虚拟机调度会影响微秒级分位数，不能用这三轮作跨机器的统计显著性保证。原始逐轮数值与样本保留。

## 600 秒并发与更新

amd64 共享 VPS；测试 cgroup 限制 0.75 CPU/768 MiB，保持低优先级，未停其他服务。10k 高级规则、128 条常驻连接，加持续新连接；配置 1 秒统计周期并并发启停其他转发。实际结果：

- 持续 **600.01 秒**；完成 **27260** 次内容校验交换、**5452** 次新连接，传输错误 **0**。
- **306** 次有效累计报告、**58** 次配置变更；统计因处理耗时未达到严格 1 Hz，报告使用累计水位保证重试不重复记费。
- Agent RSS 中位约 **141.0 MiB**、峰值 **254.4 MiB**；后段暖窗口中位比前段增加约 **2.55 MiB**。这是本时段有界证据，不是长期无泄漏证明。
- 并发状态下单次热业务暂停 RPC **5.01 秒**；配置变更 p95 约 **5.33 秒**，暂停后实际 TCP/UDP 被阻断；恢复后可用。
- 负载结束后保持原状态，10k 温重启 **14.76 秒**，数据转发及累计账本恢复；独立复现测试此前也确认约 14.4 秒。
- 累计双向应用数据约 **343.8 MiB**，全部在私有链路。

最大/最小 RSS 差的初始 64 MiB 检查会把 Go 的 GC 波动当成泄漏，因此保留失败记录，改用总 RSS 预算及暖窗口中位漂移，并重新完整运行 600 秒通过。另保留了早期数据库 384 MiB 容器 OOM、重连能力缓存空窗、启动所有权二次扫描的失败与修复证据；它们未混入最终通过数据。

## 仍未执行

第 10 项的生产灰度/迁移；第 20 项的独占物理机 PMU/perf、真实掉电和更长周期 soak；P2 的 OUTPUT/hairpin、保留源地址、跨族、加密/CDN 数据通道、应用识别、多引擎在线迁移、完整 nftables 后端。逐项方案仍在 [29 项清单](forward-engine-roadmap.md)，本轮没有把这些功能静默交给 iptables。

共享“隧道组”沿用 UserTunnel 授权语义，未新增跨用户全局隧道带宽产品。域名每个来源/地址族选一个稳定地址；大量短 TTL 独立域名的刷新吞吐有明确上限。Android/iOS 是网页容器，本轮做了网页桌面/390px 响应式检查（模拟 API），业务联调使用真实后端；未产出新的原生安装包。
