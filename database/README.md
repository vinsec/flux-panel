# 公共数据库结构

基础结构为仓库根目录 `gost.sql`；前向迁移依次为 `migrations/001` 至 `006`，从原面板目录原样迁入。
006 只增加 `panel_job_run`、`panel_pending_batch`；不改已有账本。所有前向迁移可重复执行。

`flux-panel migrate --dir /schema` 显式执行这些前向迁移，`/schema` 下应同时有 `gost.sql` 和 `migrations/`。
只有全新空数据库可加 `--init`。命令读取完整文件集后才执行；非空库初始化会被拒绝。普通服务启动不执行迁移。
DDL 不保证跨整个文件集事务回滚；失败时修复原因并重跑，不能把失败视为自动回退成功。

旧 005 反迁移已经从当前树移除；如需要研究历史格式，读取 `a08e3d8` 的 Git 对象。正常 Java/Go 语言回滚不需要引擎反迁移。
